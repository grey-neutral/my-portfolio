# My Portfolio Website

This is a personal portfolio website showcasing my projects, and writings on AI in healthcare. The website is built with HTML, CSS, and JavaScript, and is hosted on GitHub Pages.

Visit:
[My portfolio](https://grey-neutral.github.io/my-portfolio/)


## Project screenshots

The original ocean design and page animations are preserved. Projects use a compact responsive grid with normal vertical scrolling.
Project images are ordinary `<img>` elements in `index.html`, stored in `images/projects/`.
Only their placement within existing cards is handled by `css/project-images.css`.
To change a screenshot, update its `src`, `width`, `height` and `alt` in the HTML.

Finmedio uses an existing prototype capture with mock data. Jaw Atlas, Anaesthesia and Visual Travel Planner use application captures. KettleCoach images are frames from its public product-tour recordings; the anatomy model attribution is in [KettleCoach’s third-party licenses](https://github.com/grey-neutral/kettlebell-coach/blob/main/THIRD_PARTY_LICENSES.md). The Clicker image comes from the author’s public X demo; its source repository stays private.

OpenCare and Matcha Atelier are captures of the actual applications running locally. OpenCare uses the project's committed Ghana data and an OpenStreetMap basemap ([© OpenStreetMap contributors](https://www.openstreetmap.org/copyright)); the original map provider required an API key at capture time. The Article Parser image is the first page of the generated research-summary document committed in its public repository. The Clicker still is the author's selected moment at 1:22 in the linked video. The Stealth project uses the author's supplied hardware photo, retouched with AI for a clean background and product framing.

Seven additional project previews were captured from their actual public source applications: AlphaPilot (initial workspace), Impact Info (built-in mock patient), Traffic Jam Physics Lab, Speech Calc Pro, UNMAPPED, Agnes and Interview Simulator. Award credits for Finmedio, AlphaPilot and KettleCoach were supplied by the portfolio author.
