# My Portfolio Website

This is a personal portfolio website showcasing my projects, and writings on AI in healthcare. The website is built with HTML, CSS, and JavaScript, and is hosted on GitHub Pages.

Visit:
[My portfolio](https://grey-neutral.github.io/my-portfolio/)


## Project screenshots

The original ocean design, animations and horizontal project scroll are preserved.
Project images are ordinary `<img>` elements in `index.html`, stored in `images/projects/`.
Only their placement within existing cards is handled by `css/project-images.css`.
To change a screenshot, update its `src`, `width`, `height` and `alt` in the HTML.

Finmedio uses an existing prototype capture with mock data. Jaw Atlas, Anaesthesia and Visual Travel Planner use application captures. KettleCoach images are frames from its public product-tour recordings; the anatomy model attribution is in [KettleCoach’s third-party licenses](https://github.com/grey-neutral/kettlebell-coach/blob/main/THIRD_PARTY_LICENSES.md). The Clicker image comes from the author’s public X demo; its source repository stays private.
